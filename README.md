I build small tools with clean interfaces on open protocols, the kind you can run on your own machine and understand in one look.

### Now

**[townhall](https://github.com/townhall-fc/townhall)**, a calm Farcaster client that runs from your own node.
Three commands: a Snapchain read node, a minimal client served from your server, and an app key of its own. No API keys, no middleman. Voters-only feed, replies from mutuals.

### How I work

- **Own the stack.** If it matters, you should be able to run it yourself.
- **Ship the smallest useful thing.** Then cut more.
- **Interfaces that explain themselves.** No manual needed.
